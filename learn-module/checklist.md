- [ ] Ikuti `learn-module/01-setup.md` untuk menyiapkan environment

- [ ] Buat branch fitur dengan nama `feat/<area>-<short>` atau `fix/<area>-<short>`
- [ ] Tambahkan tests untuk perubahan baru
