# Modul Belajar: Pengembangan Lentera

Modul ini berisi panduan langkah demi langkah untuk pengembang baru yang ingin berkontribusi pada proyek Lentera.

Struktur singkat modul:

- `01-setup.md` — setup lingkungan pengembangan
- `02-architecture.md` — ringkasan arsitektur dan konvensi kode
- `checklist.md` — checklist tugas awal untuk contributor
- `exercises.md` — latihan kecil untuk mengenal kodebase

Gunakan modul ini sebagai panduan on-boarding cepat.
