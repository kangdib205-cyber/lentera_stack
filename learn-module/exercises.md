# Exercises — Latihan Singkat

1. Tambahkan route baru di `routes/web.php` yang memanggil controller di `app/Http/Controllers/Core`.
2. Buat migration sederhana di `database/migrations` dan jalankan `php artisan migrate`.
3. Tambahkan unit test untuk service kecil di `app/Services/Core`.

Tujuan latihan: mengenal alur request → controller → service → model → migration → test.
